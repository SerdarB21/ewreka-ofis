# Katkıda bulunma

Hata bildirimlerinde modülü, işletim sistemini, uygulama sürümünü ve sorunu yeniden
oluşturma adımlarını belirtin. Özel belgeler yerine anonim örnekler kullanın.

Değişiklik önerileri için pull request açın. Derleme adımları README.md ve
src altındaki BUILD.md dosyalarındadır. İlgili modülün açma, düzenleme ve kaydetme
akışını sınayın; çalıştırdığınız kontrolleri pull request açıklamasına yazın.

Katkılar projenin GNU AGPL-3.0-only lisansıyla sunulur.
Üçüncü taraf telif, lisans ve NOTICE bildirimlerini koruyun.
Yeni bağımlılıkların lisanslarını kontrol edin ve lisans bildirimlerini güncelleyin.
